# Bible datasets

- `pt-BR.json`: Almeida 1819 (Bíblia Livre), public domain.
- `en.json`: World English Bible (WEB), public domain.

Both datasets are generated from [midvash/bible-data](https://github.com/midvash/bible-data). The adjacent `*.metadata.json` files preserve each edition's source provenance and license declaration. Run `npm run fetch:bible` to refresh them.
